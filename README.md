# 📊 Sales Intelligence Dashboard

An interactive Sales Intelligence Dashboard built using **HTML, CSS, JavaScript, and Chart.js** to analyze sales performance and generate meaningful business insights.

The dashboard provides a visual overview of sales, profit, orders, products, categories, cities, and sales representatives.

## 🚀 Project Overview

This project demonstrates how data can be transformed into an interactive dashboard to help users understand business performance and identify important sales trends.

The dashboard includes interactive charts, KPI cards, filters, and visualizations for better data analysis.

## ✨ Features

- 📈 Interactive sales and profit visualizations
- 💰 Key Performance Indicators (KPIs)
- 🛒 Order and sales analysis
- 📦 Product performance analysis
- 🏷️ Category-wise sales analysis
- 🌆 City-wise sales analysis
- 👥 Sales representative performance
- 📊 Interactive charts using Chart.js
- 🎨 Responsive and user-friendly dashboard interface
- 🔎 Data-driven business insights

## 🛠️ Technologies Used

- **HTML5** – Dashboard structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Dashboard functionality and data processing
- **Chart.js** – Interactive charts and visualizations

## 📌 Key KPIs

The dashboard focuses on important business metrics such as:

- Total Sales
- Total Profit
- Total Orders
- Product Performance
- Category Performance
- Sales Representative Performance
- City-wise Sales

## 📊 Dashboard Analysis

The dashboard helps answer questions such as:

- Which products generate the highest sales?
- Which categories perform best?
- Which cities contribute the most to sales?
- Which sales representatives have the best performance?
- What are the major sales and profit trends?
- Which areas may require improvement?
